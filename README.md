# Visual DSA

An Angular application for learning data structures and algorithms through interactive visualizations.

## Requirements

- Node.js 24.19 or another version supported by Angular 21
- npm

## Start the app

```bash
npm install
npm start
```

The development server runs at `http://localhost:4200/`.

## Stack

- Angular 21 with standalone components and Angular Router
- PrimeNG 21 with the Aura theme and PrimeIcons

Add application pages as standalone components and register them in `src/app/app.routes.ts`. Import PrimeNG components individually where they are used.
